# 急速变色龙（jifen3d）· 完整复现步骤

4399 小游戏《急速变色龙》的完整拆解流程，可照做复现。

**目标**：`4399.com/flash/188739.htm`
**结果**：27.13 MB 的 Unity 导出 Flash，1,324 个反编译文件，15 个关卡

| 工具 | 说明 |

## 第 1 步：找真实资源地址

**最容易踩的坑：页面站不托管 SWF。**

```python
import re, urllib.request

PAGE = 'https://www.4399.com/flash/188739_1.htm'
req = urllib.request.Request(PAGE, headers={'User-Agent': 'Mozilla/5.0'})
html = urllib.request.urlopen(req).read().decode('gbk', 'replace')

game_path = re.search(r"_strGamePath\s*=\s*['\"]([^'\"]+)", html).group(1)
print('path:', game_path)
# /upload_swf/ftp22/tangyongfeng/20170613/5/jifen3d_https.htm

# 真实资源域名在 server8.js 里，不在页面里
js = urllib.request.urlopen(
    'https://www.4399.com/js/server8.js', timeout=20).read().decode('utf-8', 'replace')
server = re.search(r'webServer\s*=\s*["\']([^"\']+)', js).group(1)
print('host:', server)
# //flashs1.4399.com/4399swf
```

URL 拼法：

```
https://flashs1.4399.com/4399swf + /upload_swf/ftp22/tangyongfeng/20170613/5/main.swf
```

**验证锚点**：页面标注「10.39 MB」，实际 `main.swf` = 10,392,883 字节。

```bash
curl -O https://flashs1.4399.com/4399swf/upload_swf/ftp22/tangyongfeng/20170613/5/main.swf
ls -l main.swf        # 10392883
```

## 第 2 步：解三层嵌套

```bash
python tools/swf_extract.py main.swf out/
```

输出：

```
[1] main.swf  10392883 bytes
[2] unwrapped  10666700 bytes
    stage 800x500  60.0 fps  2 frames
    DefineBinaryData chid=13    len=10282290
[3] payload  out/13_L4399Main_gamefile.bin  10282290 bytes
[4] binary   out/game_inner.swf  27128915 bytes
    stage 800x500  60.0 fps  3 frames
```

结构对照：

| 层 | 大小 | 属性 |
|---|---|---|
| 容器 htm | 1,690 B | 只有 `<object>` 指向 main.swf |
| 壳 main.swf | 10,392,883 B | CWS · v19 · 800×500 · 60fps · 2 帧 |
| 载荷 bin | 10,282,290 B | `DefineBinaryData` chid=13 |
| 本体 swf | 27,128,915 B | CWS · v19 · 60fps · 3 帧 |

本体 SHA-256：

```
2439CD1DA41B124D5EBACEEE18B73642D27195E9F8FA10325B37158050C533BD
```

> 复现时哈希应该一致。不一致说明中间某步有问题。

### 关于那个「解密」

壳里有完整的 `Decryption.as`（分块读 + 逐字节 XOR + `loadBytes`），但：

```actionscript
private var game_key:String = "";        // 空密钥 → 没加密
```

载荷头部 `43 57 53` = `CWS`，直接 zlib 解。

**先读常量，再写解密器。**

```bash
ls out/scripts/ | head
```

看到 `com.unity.UnityNative` + `UnityEngine.*` → **Unity 导出的 Flash**。

## 第 4 步：定位核心逻辑

```bash
cd out/scripts/global
ls | grep -E "变|色"
```

```
Player_SenTiYanSe.as     身体颜色
ErDuanTiaoBianSe.as      二段跳变色
TuoWeiBianSe.as          拖尾变色
```

### 读出来的东西

**角色是 13 部件骨骼精灵**

```actionscript
躯干 · 头
右上臂 · 右下臂 · 右手 · 右肘
左上臂 · 左下臂 · 左手
枪械 · 身体所有部件[]
```

每帧把自身 `color` 广播给全身 —— 整只龙同步换色。

**变色 = 二段跳额度指示器**

```actionscript
public function ErDuanTiaoBianSe_Update() : void
{
   if(Player_KongZhi(...).Player_KongZhi$空中跳力量$ == 0)
      color = 无力量颜色;         // 跳次数用完 → 变暗
   else
      color = 原始颜色;           // 还有 → 原色
}
```

**这不是美术效果，是状态指示。** 玩家靠颜色判断还能跳几次。

**长按蓄力跳没实现**

```actionscript
public function Player_KongZhi_长按加力跳_KeyCode($按键:KeyCode) : void
{
}
```

空函数体。功能规划过、接口留了、最终没做。

### 动作系统全貌

`Player_KongZhi.as` 的字段就是配置表：

| 字段 | 含义 |
|---|---|
| `移动速度` / `最高移动速度` / `额外速度` | 速度三层叠加 |
| `地面加速度` / `空中加速度` / `额外阻力` | 空中地面两套手感 |
| `在地板上` / `在底层平台` | 接地判定 |
| `跳跃高度` / `空中跳力量` / `默认空中跳跃力量` | 跳跃系统（额度制） |
| `地板恢复跳跃力量真空期` | 落地回充冷却 |
| `最大重力速度` / `最大跳起的时间` | 重力封顶 / 长按上限 |
| `踩踏间隔` / `踩踏限制器` | 踩怪节奏限制 |

键位：`p1_left` / `p1_right` / `p1_jump` / `p1_att1..att5`

帧流程：

```
1. 真空期倒计时
2. 在地板上 && 真空期 < 0 → 空中跳力量 = 默认值        ← 回充
3. 反转() / 模拟世界物理()
4. 键盘控制 / AI 状态机
5. 在底层平台 → 取消跳下作用()
```

## 第 5 步：跑起来

### 浏览器版会失败

Ruffle 网页版会停在 `allowScriptAccess` 错误。追到 `com/frames/FB.as`：

```actionscript
else if (!appModel.easy) {
   showError(getLabel("allowScriptAccess"), null);
   return;
}
```

`easy` 的判定链：

```
AppModel.easy
  └─ Platform.inPlatform(name)
       └─ m_types.indexOf(name) > -1
          || URL.checkDomain(GreenGlobal.domain, name)
               └─ JS.topDomain
                    └─ ExternalInterface.call("top.location.hostname.toString")
```

浏览器沙箱下这条链不通（实测注册的回调一次都没被调用）。

### 桌面版可以

```bash
ruffle.exe out/game_inner.swf
```

桌面版 `Capabilities.playerType` 返回 `StandAlone`：

```actionscript
public static function get isBrowser() : Boolean {
   var t:String = Capabilities.playerType;
   return t == "ActiveX" || t == "PlugIn";       // StandAlone → false
}
```

`RE.isBrowser = false` → **整个检查跳过** → 游戏启动。

### 实测表现

| 阶段 | 画面 |
|---|---|
| 标题 | 「急速变色龙」粉字、粉色拖尾、滑板上的红帽变色龙、EN/CN + 音乐 + 加号 |
| 进关 | 夜空海面、城市剪影、金色轨道、白色粒子拖尾 |
| 按 W | 角色变橙黄、拖尾转红黄、出现跳跃平台、提示「轻按 'W' 或 '鼠标左键' 起跳」 |

第三步验证了源码推理：变色确实是二段跳额度的指示。

## 一页速查

```
1. 抓页面 → 搜 server8.js 的 webServer → 真实资源域名
2. 核对页面标注体积，验证抓对文件

4. FFDec 导 script，看包名判断引擎
5. 按大小排序，中间段落是业务类
6. grep 中文/拼音类名 → 锁定核心
7. 只读 Update() 和 public var
8. 空函数体记下来（未完成功能）
9. 跑不起来先看平台壳，再换运行环境
10. 字节码修改是最后手段
```
